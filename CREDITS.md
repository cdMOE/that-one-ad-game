# Credits

## Code

Everything in this repository is original work, released under the [MIT License](LICENSE).

## Graphics

All visuals are drawn in code with canvas shapes and CSS. No external image assets are used.

## Audio

All sound effects are synthesized at runtime with the WebAudio API (`src/audio/sfx.ts`). No audio
files are used.

## Fonts

The game uses the system font stack. No web fonts are loaded.
